02 · STRUCTURAL FORMALISM

Deterministic composition

The formal layer specifies the objects and operations used throughout the AUF framework. Definitions are intended to remain explicit, finite and mechanically inspectable.

X = { x₁, x₂, …, xₙ }

C : X × X → X

C(xᵢ, xⱼ) = xₖ

∀ xᵢ, xⱼ ∈ X
STRUCTURAL CONDITION
Every admissible composition is represented by an explicitly defined operation over the finite structural domain.

No implicit state transition is assumed.
