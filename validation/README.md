AUF2026 — Validation

This directory contains validation and reproduction records.

Validation layers

Validation is separated into:

internal computational checks;

formal verification;

independent computational reproduction;

independent mathematical examination;

experimental or empirical validation where applicable.

Each record identifies exactly which layer has been performed.

Required record

A validation record should contain:

claim identifier;

input;

method;

software;

version;

output;

expected result;

observed result;

reproduction instructions;

date;

evaluator or reproducer where publicly identifiable.

No validation status is assigned beyond the evidence actually recorded.
