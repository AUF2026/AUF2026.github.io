AUF2026 — Formal Proofs

This directory contains formal verification artifacts.

Scope

Artifacts may include:

Lean 4 source;

Mathlib dependencies;

theorem statements;

definitions;

examples;

test files;

build instructions;

compiler information;

dependency versions.

Reproducibility record

Every formal proof should identify:

Lean version;

Mathlib revision;

source file;

theorem name;

imports;

compilation result.

Interpretation

A formal proof establishes the corresponding proposition within the stated formal system and assumptions.

Broader scientific interpretations are documented separately.
