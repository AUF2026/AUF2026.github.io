AUF2026 — Papers

This directory contains the canonical research manuscripts associated with the AUF2026 research program.

Archive principles

Each manuscript should preserve:

title;

author;

original publication date;

source URL;

version;

complete text or archival copy where legally permitted;

references;

associated computational artifacts;

associated formal proofs;

validation status.

Versioning

Original documents are preserved as distinct versions whenever possible.

No retrospective modification of an original manuscript is represented as the original text.

Corrections and clarifications are recorded separately.

Evidence status

Each research claim is classified independently according to its available evidence.

Suggested status values:

DOCUMENTED

FORMALLY_VERIFIED

COMPUTATIONALLY_REPRODUCED

INDEPENDENTLY_REPRODUCED

PEER_REVIEWED

OPEN_REVIEW

Status describes the evidence available for the specific claim and does not constitute a general assessment of the entire framework.
