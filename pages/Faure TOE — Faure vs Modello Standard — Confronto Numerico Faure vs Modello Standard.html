Riferimenti e livelli di stato

  • LOCAL CORPUS: tutti i file Lean e Python elencati nelle sezioni precedenti.
  • DECLARATIONS / DEPENDENCIES / DAG: determinati dai file Lean core (P1‑P16, Tupla Universale, Tupla Primitiva, FDM) e dai log di build.
  • EVIDENCE MANIFEST: FORMAL_VERIFICATION_CORPUS_MANIFEST.md, COMPUTATIONAL_SUPPLEMENT_MANIFEST.md, CLAIMS_AND_VERIFICATION_STATUS.md.
  • P1 / STRUCTURAL CORE / FAURE / 90 CLAIMS: ricostruiti e mappati nei manifest; lo stato di ciascun claim deve essere esplicito (stabilito / concettuale / non stabilito).
  • REPRODUZIONE: app AOS144, WATER, NSSE/MSSE, validatori Python.
  • HTML AUDIT APPLICATION: questa pagina, che non aggiunge prova matematica ma rende trasparente lo stato del corpus.
Separazione netta: FILE ≠ RISULTATO • HTML ≠ PROVA • CONCETTUALE ≠ FORMALE • FORMAL VERIFICATION ≠ PHYSICAL VALIDATION • LEAN BUILD SUCCESS ≠ SCIENTIFIC NOVELTY • SCIENTIFIC NOVELTY ≠ PHYSICAL TRUTH.
