Additional corpus

The public Medium profile contains additional AUF2026 publications not yet assigned individual permanent archive identifiers.

These must be imported in chronological order and assigned identifiers without changing the original publication.

Import protocol

For each publication:

preserve original title;

preserve publication date;

preserve original URL;

archive available full text where legally permitted;

extract mathematical definitions;

extract theorem statements;

extract equations;

extract algorithms;

extract computational claims;

identify referenced external literature;

identify source code;

identify datasets;

create claim identifiers;

create theorem identifiers;

create validation identifiers;

connect all objects in the research register.

Evidence rule

Publication in the corpus establishes provenance of the document.

It does not, by itself, establish independent verification of every mathematical, physical or computational claim contained in that document.

Evidence is recorded at claim level.
