Naming rule

Public scientific names use descriptive names.

Internal identifiers use stable identifiers:

THM-001
THM-002
APP-001
COMP-001
EXP-001
VAL-001


A public theorem name may therefore be:

Faure Theorem of [descriptive subject]


while its internal archive identifier remains:

THM-001

Version rule

AOS V1.0, AOS120, AOS250, AOS600 and other computational configurations are registered as configurations.

They are not automatically treated as different mathematical kernels.

The archive records the actual differences:

precision;

algorithm;

input;

output;

implementation;

theorem dependency;

computational environment.

Evidence rule

DOCUMENTED means the object has been located in a public source.

It does not mean:

independently verified


Those states are recorded independently.
